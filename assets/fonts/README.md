# Invoice PDF fonts (optional)

For offline invoice PDF generation, add:

- `Almarai-Regular.ttf`
- `Almarai-Bold.ttf`

from [Google Fonts – Almarai](https://fonts.google.com/specimen/Almarai).

If these files are missing, the app downloads the same files from `fonts.gstatic.com` on first PDF export (requires network).
